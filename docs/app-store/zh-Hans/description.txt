AI Native，随手开读。
原生支持 Markdown、HTML、PDF，把 AI 生成与整理的知识库带在身边。

在电脑上用 Claude Code、Codex 等 AI 工具整理笔记、生成报告、归纳阅读资料，在 iPhone 和 iPad 上用 Vault Reader 随时阅读、快速查找、接着读。

为 AI 时代的知识库而设计
知识以文件的形式存在，AI 工具在应用之外整理文件，Vault Reader 连接你的 GitHub 或 GitLab 仓库，专注阅读体验。只读访问，不会修改你的原始文件。

Markdown、HTML、PDF，原生支持
• Markdown：阅读笔记、文档与讲义，支持常用双链、嵌入、表格与代码块。
• HTML：打开 AI 生成的报告、阅读页面和交互内容。
• PDF：阅读书籍、论文和原始资料，用原生 PDF 阅读器翻页和续读。

随时打开，接着读
调整字号与阅读主题，使用标题目录找到章节。阅读位置保存在本机，已缓存的文件可以离线阅读。

找到需要的那一页
搜索文件名和已缓存的 Markdown 正文，从最近提交中查看新生成或更新的内容。在多个知识库之间切换。

先体验，再连接
无需账号即可打开内置示例。连接自己的仓库需要 GitHub 或 GitLab 账号与只读 Token；Token 保存在设备钥匙串，不进入网页渲染层。

免费，无广告、内购或订阅。阅读进度暂不跨设备同步；部分 HTML 和外部图片需要联网，Obsidian 插件及 Git LFS 文件内容不受支持。应用不提供内置 AI 聊天、生成或编辑。首版界面主要为简体中文，附英文使用帮助。
