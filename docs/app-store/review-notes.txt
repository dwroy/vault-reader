Vault Reader is a native, read-only viewer for user-selected GitHub/GitLab repositories. It has no app account, purchases, subscriptions, advertisements or built-in AI service. AI Native refers to a workflow where external AI tools may maintain the user's files; the app does not call AI APIs or transmit documents to AI services.

English is the app's default/fallback language. The interface follows iOS preferred languages and supports English, Simplified/Traditional Chinese, Japanese, Korean, Spanish, Brazilian Portuguese, French, German, Arabic, Hindi and Indonesian. iOS Settings allows per-app language selection. Repository contents retain their original language. Full help and privacy documents are available in English and Simplified Chinese, with a notice in other interfaces.

To review without credentials in English:
1. On Welcome, tap Try sample library.
2. Files displays bundled, original synthetic notes. Open README.md, follow links to Guide.md and the example note, or open an image. No personal files are included.
3. Open Reading, then example/synthetic-vault, then Night Voyage. Its PDF and Markdown editions exercise native reading and local resume. Reader.html in Files exercises independent HTML content and local browser storage.
4. Search supports filenames and cached Markdown text. Recent shows synthetic commits. Another sample library is available from the Files project switcher.
5. A Markdown note's upper-right menu offers Share using the native share sheet.
6. Terminate and relaunch: the sample library persists. Files → menu → Settings → Leave sample library exits the samples. Privacy Policy and Setup guide & support are readable offline.

Chinese interfaces use the equivalent Chinese sample library and labels: 体验示例知识库, 目录, 阅读, 夜航手记 and 退出示例知识库.

The sample library is a public feature in the submitted Release binary. It makes no network requests to GitHub/GitLab. Optional personal repository connections use a read-only token entered by the user into the device Keychain, never exposed to web content. We can arrange a dedicated synthetic repository for live synchronization review if needed; no personal repository credentials are included here.
