AI Native. 언제든 읽으세요.
Markdown, HTML, PDF를 바로 읽는 나만의 지식 라이브러리.

Claude Code, Codex 등 외부 AI 도구로 노트와 자료를 정리하고, iPhone과 iPad의 Vault Reader에서 읽으세요. GitHub, GitLab.com 및 HTTPS 자체 GitLab에 연결할 수 있습니다. 읽기 전용이므로 원본 파일을 변경하지 않습니다.

• Markdown: 노트, 문서, 위키 링크, 임베드, 표와 코드 블록.
• HTML: 보고서와 인터랙티브 문서.
• PDF: 기본 PDF 리더로 책과 논문을 읽고 마지막 페이지부터 이어 읽기.

글자 크기와 테마를 바꾸고 목차로 이동하세요. 여러 저장소를 전환하고 파일명 및 캐시된 Markdown 본문을 검색할 수 있습니다. 최근 커밋으로 새 파일과 변경 내용을 확인하세요. 캐시된 파일은 오프라인에서도 읽을 수 있으며 읽던 위치는 기기에 저장됩니다.

내장 예제는 계정 없이 체험할 수 있습니다. 개인 저장소에는 읽기 전용 토큰이 필요합니다. 토큰은 기기 키체인에 저장되며 웹 콘텐츠에 노출되지 않습니다.

무료이며 광고, 앱 내 구입, 구독이 없습니다. 내장 AI 채팅, 생성 또는 편집 기능은 없습니다. 읽기 진행률은 기기 간 동기화되지 않습니다. 일부 HTML과 외부 이미지는 인터넷 연결이 필요합니다. Obsidian 플러그인과 Git LFS 실제 파일 내용은 지원하지 않습니다.

한국어를 포함한 12개 언어를 지원하며 지원하지 않는 언어는 영어로 표시합니다. 문서는 원래 언어를 유지합니다. 예제와 전체 도움말·개인정보 문서는 영어와 중국어로 제공됩니다.
