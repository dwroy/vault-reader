AI Native. Ready to read.
Native support for Markdown, HTML and PDF brings your AI-assisted knowledge base with you.

Use tools such as Claude Code or Codex on your computer to organize notes, generate reports and prepare reading material. Open those files on your iPhone or iPad with Vault Reader.

Built for a knowledge base maintained with AI
Your knowledge lives in files. External AI tools maintain them; Vault Reader connects to GitHub or GitLab and focuses on reading. Access is read-only, so the app never edits your original files.

Markdown, HTML and PDF
• Markdown: read notes and documents with common wikilinks, embeds, tables and code blocks.
• HTML: open reports, reading pages and interactive documents, including files created with AI tools.
• PDF: read books, papers and source material with the native PDF reader and local page resume.

Read and pick up where you left off
Adjust reading size and themes, browse headings and return to your saved position. Cached files are available offline.

Find the page you need
Search filenames and cached Markdown text. Browse recent commits to find new or updated files, and switch between multiple repositories.

Try it before connecting
The built-in sample library needs no account. Your own repository requires a GitHub or GitLab account and a read-only token. Tokens stay in the device Keychain and are never exposed to the web renderer.

Free, with no ads, purchases or subscriptions. Reading progress stays on this device. Some HTML and external images require a network connection. Obsidian plugins and Git LFS file contents are not supported. The app has no built-in AI chat, generation or editing. The initial interface is primarily Simplified Chinese, with an English setup guide.
