AI Native. جاهز للقراءة.
مكتبتك المعرفية مع دعم مدمج لملفات Markdown وHTML وPDF.

نظّم الملاحظات والتقارير بأدوات خارجية مثل Claude Code أو Codex، ثم اقرأها على iPhone وiPad باستخدام Vault Reader. اربط GitHub أو GitLab.com أو خادم GitLab الخاص بك عبر HTTPS. الوصول للقراءة فقط ولا يغيّر ملفاتك الأصلية.

• Markdown: ملاحظات ومستندات وروابط ويكي ومحتوى مضمّن وجداول وكود.
• HTML: تقارير ومستندات تفاعلية.
• PDF: كتب وأبحاث بالقارئ الأصلي مع العودة إلى الصفحة المحفوظة.

غيّر حجم النص والمظهر، واستخدم الفهرس، وانتقل بين المستودعات. ابحث في أسماء الملفات ونصوص Markdown المخزنة. راجع الإيداعات الأخيرة لمعرفة الجديد. الملفات المخزنة متاحة دون اتصال، ويُحفظ موضع القراءة على هذا الجهاز.

جرّب المكتبة النموذجية دون حساب. لربط مستودعك، استخدم رمز وصول للقراءة فقط. يبقى الرمز في سلسلة مفاتيح الجهاز ولا يُمرّر إلى محتوى الويب.

مجاني، بلا إعلانات أو مشتريات أو اشتراكات. لا يتضمن محادثة أو توليدًا أو تحريرًا بالذكاء الاصطناعي. لا تُزامن مواضع القراءة بين الأجهزة. قد تتطلب بعض ملفات HTML والصور الخارجية اتصالًا بالإنترنت. إضافات Obsidian ومحتوى ملفات Git LFS غير مدعومة.

يدعم 12 لغة، منها العربية بواجهة من اليمين إلى اليسار، ويستخدم الإنجليزية عند غياب اللغة المطلوبة. تحتفظ المستندات بلغتها الأصلية. الأمثلة والمساعدة الكاملة وسياسة الخصوصية متاحة بالإنجليزية والصينية.
